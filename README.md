# DriveStream - One-Page Car Website

DriveStream is a modern, responsive, and high-performance single-page automotive website. It is specifically designed for car dealerships, showrooms, and luxury vehicle rentals to showcase their fleet, highlight key performance features, and capture user inquiries through a clean and intuitive user interface.

---

## Features

### Single-Page Navigation
* **Smooth Scrolling:** Seamless transitions between sections such as Home, Fleet, Features, Testimonials, and Contact.
* **Sticky Navigation Bar:** Easy browsing access from anywhere on the page.

### Vehicle Showcase
* **Interactive Fleet Section:** High-quality image grid or carousel highlighting premium vehicles with brief specifications (pricing, fuel type, transmission, horsepower).
* **Detailed Features Layout:** Dedicated section explaining advanced vehicle metrics and highlights.

### User Engagement
* **Booking / Inquiry Form:** Fully functional frontend form allowing users to request test drives or quotes.
* **Customer Testimonials:** Grid or carousel layout displaying trust badges and user reviews.
* **Fully Responsive Design:** Optimized for seamless performance on desktops, tablets, and smartphones.

---

## Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap (for flexible layout structures)
* **Design Standards:** Modern typography, optimized asset loading, and clean CSS animations
